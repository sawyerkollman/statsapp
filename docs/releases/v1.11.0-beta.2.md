# v1.11.0-beta.2 — neon themes and overview

User requested synthwave themes and a flashier beta overview, then explicitly authorized beta.2 publication
after validation. Base `e7b57ae`; implementation branch `feature/beta-synthwave`. Stable/master stay unchanged.

## Changes

- Three additional, opt-in presets: Synthwave (magenta/cyan), Outrun (sunset pink/orange), Midnight (ice blue).
- New presets show a compact Neon overview in Auto layout: static vector sunset/grid, four live selected
  CPU/GPU/Memory/Game readings, Compare and Recordings shortcuts. Free/Grid retain their exact canvas.
- Reuses existing metric tile instances and commands; missing readings remain missing. No new hardware
  access, polling, timer, settings schema, animation loop, raster assets or dependency.
- All five old presets/defaults preserved; selecting a classic theme removes the overview live.

## Source validation

- Final Release build: zero warnings/errors. Full suite: 979 Core + 305 preview = 1,284 passed, no skips.
- New behavior coverage: preset sanitation, exact tile reference reuse/order/removal, live missing readings,
  WPF resource replacement/reset. Existing contrast matrix automatically includes all three new presets.
- Palette contrast minima reported/calculated by theme worker: small text >=5.17:1, accent >=4.14:1;
  existing automated 4.5:1 text / 3:1 focus-boundary gates pass across all presets.
- Independent Sol source review: no material findings. Shared dynamic-resource replacement, warning/critical
  semantics, native keyboard/automation labels, preview isolation and fan/poller invariants preserved.
- One mechanical theme compile repair (local variable naming); two bounded overview visual refinements
  (dark surfaces/semantic severity, then right-side static artwork). Source frozen after repairs.
- Preview-only repair: ComboBox slide animation did not settle while the harness drained dispatcher queues.
  Disable that transient animation only in the dropdown capture path and fail if the picker/popup is absent
  or not visibly open. Native screen capture now shows all eight theme choices; production behavior is unchanged.

## Use

Enable Receive beta updates under Settings > System and check for updates. After installing beta.2,
choose Synthwave, Outrun or Midnight under Settings > Appearance. Use Auto layout for the Neon overview.
Existing installations retain their current theme until the user changes it.
