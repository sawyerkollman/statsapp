# Beta Lab expansion

User explicitly requested all twelve brainstorm features, plus overhead/resilience/privacy work.
Integration branch: `feature/beta-lab`, base `0937124`. No release or master merge is authorized.
This extends historical UI-polish feature restrictions, not hardware, privacy or compatibility rules.

## Delivery contracts

1. Session time machine: open existing recordings, scrub/step/play a dated read-only replay,
   bookmarks and notes; live monitoring and fan safety continue unchanged. Large files use bounded
   windows read from the original JSONL, not an unbounded in-memory session. Missing stays missing.
2. Performance detective: measured associations with sample counts/coverage and explicit limitations;
   never label a correlation a proven bottleneck or invent frame statistics from poll averages.
3. Gaming cockpit: per-game scene picks, optional automatic recording (off by default), and post-game
   report. Reuse frame reader identity and existing signals; never enable fan control or ETW implicitly.
4. A/B lab: load two recordings, compare common metrics over equal elapsed-time windows, show
   coverage/duration and absolute/relative changes, notes about changed settings. No causal claims.
5. Scene builder: reuse layout profiles/tile editing; add grouped sections/labels and portable scene
   import/export with explicit metric mapping, no personal IDs or executable content in exports.
6. Local history: opt-in compact aggregation, configurable retention and disk cap; local only,
   bounded memory/queues, failure status. Never delete manually saved recordings as retention.
7. Theme studio: primary/secondary decoration accents, curated surface presets, gradients,
   named local presets and portable validated theme import/export; preserve semantic text/severity.
   Add CRT Terminal, Arctic Glass, Reactor, Deep Space. Existing defaults unchanged.
8. Cinema mode: fullscreen current monitor, escape restores bounds/style; second-monitor move
   through normal Windows controls. Readable gauges, low-motion/effects budget, no extra poller.
9. Reactive decoration: opt-in native vectors driven by existing readings, explicitly decorative,
   missing-data state, no independent perpetual animation loop; respects reduced effects.
10. Overlay composer: named game/stream/debug scenes capturing selection and supported layout/style;
    keep pinned colors, click-through, hotkey and explicit move mode. No capture/injection hooks.
11. Timeline/smarter alerts: bookmarks, detected game transitions, threshold and missing-sensor events;
    compound rules with explicit hold/cooldown/test mode, bounded persistence. Existing rules unchanged.
12. Tuning assistant: local evidence-backed experiment checklist and A/B links, not overclocking or
    automatic hardware writes. Fan experiments are notes with explicit existing manual controls only.
13. Quality: measured Stats overhead, bounded storage, interrupted-file recovery, long-run checks,
    diagnostic export preview with allowlisted non-personal metadata, no automatic upload.

- B: theme studio, cinema/reactive visuals, scene builder and overlay composer.
